## Methods

### Upload

Use: `images.upload(file, options?)`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | `File \| Blob` | Required | File/blob payload. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<UploadImageResponse>`.

### Delete

Use: `images.delete(imageId, options?)`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `imageId` | `number` | Required | Uploaded image ID. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

## `UploadImageResponse` fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `number` | Required | Image ID. |
| `url` | `string` | Required | Public image URL. |
| `filename` | `string` | Required | File name. |
| `size` | `number` | Required | File size in bytes. |
| `mime_type` | `string` | Required | MIME type. |

<Callout type="warning">
  Do not set a manual <code>Content-Type</code> header for multipart uploads.
</Callout>
