## Method

### Query

Use: `search.query(query, filters?, options?)`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | `string` | Required | Search query text. |
| `filters.page` | `number` | Optional | Page number. |
| `filters.pageSize` | `number` | Optional | Page size. |
| `filters.categoryId` | `number` | Optional | Category filter. |
| `filters.minPrice` | `number` | Optional | Minimum price. |
| `filters.maxPrice` | `number` | Optional | Maximum price. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<SearchResponse>`.

## `SearchResponse` fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `products.items` | `Product[]` | Required | Product results. |
| `blogPages.items` | `BlogPage[]` | Required | Blog page results. |
| `cmsPages.items` | `CmsPage[]` | Required | CMS page results. |
| `productCategories.items` | `ProductCategory[]` | Required | Category results. |
| `*.total` | `number` | Required | Total items in result set. |
| `*.page` | `number` | Required | Current page. |
| `*.pageSize` | `number` | Required | Page size. |
