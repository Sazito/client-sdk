## Module role in sales flow

`orders` is for post-checkout access in authenticated sessions.

- Use this module for order history and order detail pages after checkout.
- For guest checkout completion, immediate order data comes from `payments.initialize()` when `action === 'showOrder'`.
- After user login, use `orders.list`/`orders.get` for long-term order retrieval.

## Methods

### List

Use: `orders.list(filters?, options?)`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `filters.pageNumber` | `number` | Optional | Page number (default `1`). |
| `filters.pageSize` | `number` | Optional | Page size. |
| `filters.filters` | `Array<{ name: string; value: any }>` | Optional | Backend filters payload (for example `self_only`). |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<OrdersListResponse>`.

```ts
const ordersRes = await client.orders.list({
  pageNumber: 1,
  pageSize: 20,
  filters: [{ name: 'self_only', value: true }],
});
```

### Get

Use: `orders.get(orderId, options?)`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `orderId` | `number` | Required | Order ID. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<Order>`.

```ts
const ordersRes = await client.orders.list({ pageNumber: 1, pageSize: 1 });
const firstOrderId = ordersRes.data?.orders?.[0]?.id;

if (firstOrderId) {
  const orderRes = await client.orders.get(firstOrderId);
}
```

## `Order` key fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `number` | Required | Order ID. |
| `orderNumber` | `string` | Required | Human-readable order number. |
| `orderIdentifier` | `string` | Required | Stable order identifier token. |
| `invoice.invoiceItems` | `InvoiceItem[]` | Required | Purchased items. |
| `invoice.shippingItems` | `any[]` | Required | Shipping assignments on order invoice. |

## Known errors

| Type | When it happens |
| --- | --- |
| `api` | Missing/invalid authentication token or inaccessible order. |
