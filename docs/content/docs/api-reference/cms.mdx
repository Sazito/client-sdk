## Methods

### Get Page

Use: `cms.getPage(urlPath, options?)`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `urlPath` | `string` | Required | CMS page URL path, e.g. `/about-us`. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<CMSPage>`.

Throws: when resolved route is not a non-blog CMS page.

### List Pages

Use: `cms.listPages(filters?, options?)`.

### Get Blog Post

Use: `cms.getBlogPost(urlPath, options?)`.

Returns blog page by URL path.

Throws: when resolved route is not a blog page.

### List Blog Posts

Use: `cms.listBlogPosts(filters?, options?)`.

### List All

Use: `cms.listAll(filters?, options?)`.

For list methods, `filters` fields are:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `filters.page` | `number` | Optional | Page number. |
| `filters.pageSize` | `number` | Optional | Page size. |
| `filters.cmsPageTypes` | `'normal' \| 'blog' \| Array<'normal' \| 'blog'>` | Optional | Explicit CMS type filtering. |

## `CMSPage` key fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | `string` | Required | Page name/title. |
| `url` | `string` | Required | URL path. |
| `cmsPageType` | `'normal' \| 'blog'` | Optional | Page type. |
| `content` | `string` | Optional | Full page content. |
| `summary` | `string` | Optional | Summary/excerpt. |
| `image` | `Image` | Optional | Featured image. |
