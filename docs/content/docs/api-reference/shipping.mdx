## Methods

### `shipping.createAddress(address, options?)`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `address.firstName` | `string` | Required | Recipient first name. |
| `address.lastName` | `string` | Required | Recipient last name. |
| `address.mobilePhone` | `string` | Required | Recipient mobile phone. |
| `address.regionId` | `number` | Required | Region ID. |
| `address.cityId` | `number` | Required | City ID. |
| `address.address` | `string` | Required | Street address. |
| `address.phoneNumber` | `string` | Optional | Secondary phone number. |
| `address.email` | `string` | Optional | Contact email. |
| `address.postalCode` | `string` | Optional | Postal code. |
| `address.latitude` | `number` | Optional | Geo latitude. |
| `address.longitude` | `number` | Optional | Geo longitude. |
| `address.userSetCoordinatesBefore` | `boolean` | Optional | Manual coordinate flag. |

### `shipping.updateAddress(address, options?)`

Same input schema as `createAddress`.

### `shipping.getAddress(options?)`

Returns: `SazitoResponse<ShippingAddress>`.

### `shipping.getMethods(options?)`

Returns: `SazitoResponse<ShippingMethod[]>`.

### `shipping.clearAddress()`

Clears persisted shipping credentials.

## `ShippingMethod` fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `number` | Required | Method ID. |
| `code` | `string` | Required | Method code. |
| `name` | `string` | Required | Method name. |
| `description` | `string` | Required | Method description. |
| `enabled` | `boolean` | Required | Availability flag. |
| `isFree` | `boolean` | Required | Free-shipping flag. |
| `isCourier` | `boolean` | Required | Courier flag. |
| `isPost` | `boolean` | Required | Postal service flag. |

## Known errors

| Type | When it happens |
| --- | --- |
| `validation` | Missing shipping credentials for `getAddress`. |
