Use this module for product grids, product pages, and product discovery.

| Use case | Method | Response data |
| --- | --- | --- |
| Product grid | `products.list(filters?)` | `PaginatedResponse<ProductListItem>` |
| Product detail page | `products.get(slugOrPath)` | `Product` |
| Cross-entity search | `products.search(query, filters?)` | `SearchResponse` |

## Methods

### Get

Use: `products.get(slugOrPath, options?)`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `slugOrPath` | `string` | Required | Product slug (`shoe-123`) or full path (`/product/shoe-123`). |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<Product>`.

Accepts a slug or full product path and returns the detail product.
All images and attributes (including description and SEO) are available here.
`themeConfig` is absent when the product has no custom page. Images, variants,
and categories preserve the API's `null` versus `[]` values.

### List

Use: `products.list(filters?, options?)`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `filters.page` | `number` | Optional | Page number. |
| `filters.pageSize` | `number` | Optional | Items per page; capped at 100 by the API. |
| `filters.sort` | `'newest' \| 'best-selling' \| 'availability' \| 'discount' \| '!price' \| 'price'` | Optional | Sort strategy. |
| `filters.categories` | `number \| number[]` | Optional | Category filter(s). |
| `filters.priceMin` | `number` | Optional | Minimum price. |
| `filters.priceMax` | `number` | Optional | Maximum price. |
| `filters.availableOnly` | `boolean` | Optional | Stock filter behavior. |
| `filters.discountedOnly` | `boolean` | Optional | Discounted products only. |
| `filters.pinnedIds` | `number[]` | Optional | Pin products on top. |
| `filters.similarTo` | `number` | Optional | Similar-to product ID. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<PaginatedResponse<ProductListItem>>`.

`items` contains `ProductListItem`
objects intended for product cards. Fetch `products.get()` for categories,
custom page configuration, description and SEO attributes, and variant SKUs.

### Search

Use: `products.search(query, filters?, options?)`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | `string` | Required | Search text. |
| `filters` | `ProductFilters` | Optional | Search uses `page` and `pageSize`. Other product-list filters are not sent by this method. |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<SearchResponse>`.

Product hits use the same
`ProductListItem` shape as lists, with a two-image default. See
[Search](/docs/api-reference/search) for the other result groups.

## Response key fields

### ProductListItem

| Field | Type | Description |
| --- | --- | --- |
| `id`, `name`, `url` | `number`, `string`, `string` | Product identity and resolved storefront URL. |
| `productType`, `enabled` | `string`, `boolean` | Product type and enabled status. |
| `imageCount` | `number` | Total product images, including images outside the returned collection. |
| `images` | `ProductImage[] \| null` | Images for the card, including variant-referenced images. |

Card attributes exclude `description`, `metaTitle`, `metaDescription`,
`metaKeywords`, `focusKeyphrase`, `redirect`, `canonical`, `noindex`, and `id`.
These attributes are available on the detail product.

### Images and optional fields

List images default to the first two images plus any images referenced by
variants, in the original order. A list item can return more than two images.
Use `imageCount` for the total number of product images. Details return all
images; count their `images` collection when it is present.

`pageSize` is capped at 100.

```ts
import type { ProductListItem } from '@sazito/client-sdk';

function cardImages(product: ProductListItem) {
  const images = product.images ?? [];
  return {
    coverUrl: images[0]?.url,
    totalImages: product.imageCount,
    remainingImages: Math.max(0, product.imageCount - images.length),
  };
}
```

The array fallback above is for presentation. The SDK preserves `null` and `[]`
as returned by the API. `themeConfig` is absent when a detail product has no
custom page; use optional access when reading it.

Product images expose `id`, `alt`, `url`, `width`, and `height`. Use `url` to
display an image and positive dimensions to calculate an aspect ratio.

### Variants, pricing, and categories

Use `variant.price` for the final price, including gold-pricing adjustments.
`originalPrice` is the raw price when present. Gold component breakdowns,
shipping weight, download links, and timestamps are not part of storefront
variants. Product timestamps and tags are not part of storefront products.

A variant contains its own attributes and identifiers. Read the product's
name and URL from the surrounding `Product` or `ProductListItem`.

Detail categories provide `id`, `name`, and `url` for breadcrumbs. To get a
category's description or product count, resolve its URL through
[Entity Routes](/docs/api-reference/entity-routes).

### Dynamic forms

Fetch the form definition when rendering a product form. Use the selected
variant's `dynamicFormId`, falling back to the product's ID when absent:

```ts
import { createSazitoClient } from '@sazito/client-sdk';

const client = createSazitoClient({ domain: 'mystore.sazito.com' });
async function loadProductForm(slug: string, variantId: number) {
  const response = await client.products.get(slug);
  if (response.error) return response;

  const product = response.data;
  const variant = product.variants?.find((item) => item.id === variantId);
  const formId = variant?.dynamicFormId ?? product.dynamicFormId;

  if (formId === undefined || formId <= 0) return null;
  return client.dynamicForms.getForm(formId);
}

const formResponse = await loadProductForm('shoe-123', 12001);
// null means no form; otherwise handle formResponse.data or formResponse.error.
```

See [Dynamic Forms](/docs/api-reference/dynamic-forms) for form fields and uploads.

### SDK response fields

Product lists return `items`, `total`, `page`, `pageSize`, and `totalPages`
inside `data`.
`products.get()` returns the detail product as `data`, including variant SKUs
when present. Use the exported SDK types and camelCase field names when
rendering product data.

### Attribute values and colors

`ProductAttribute.value` is either a display string or a rich
`ProductAttributeValueObject`. For color attributes, `fieldType` is usually
`'color'` and `extra` contains the color payload, commonly a hex value such as
`'#ff0000'`. The same normalized attribute shape is used by cart, invoice,
order, and checkout responses.

Import these types directly from the package in your application:

```ts
import type {
  Product,
  ProductListItem,
  ProductVariant,
  ProductAttribute,
  ProductAttributeValueObject
} from '@sazito/client-sdk';
```

For the full list of SDK types, see [TypeScript types](/docs/api-reference/types).
