---
title: TypeScript Types
description: Import SDK request, response, model, and module types in a host project.
---

Every public type listed below is available from the package root. Use `import type`
so the import disappears from your application's JavaScript output. No deep import
from `dist`, `src/types`, or `src/api` is needed.

```ts
import { createSazitoClient } from '@sazito/client-sdk';
import type {
  SazitoConfig,
  SazitoResponse,
  Product,
  ProductAttribute,
  CreateCartInput,
  CategoryListResponse,
  GeneralInfo
} from '@sazito/client-sdk';

const config: SazitoConfig = { domain: 'mystore.sazito.com' };
const client = createSazitoClient(config);
const productResult: SazitoResponse<Product> = await client.products.get('phone');
```

`SazitoResponse<T>` contains either `data: T` or an `error`. Import an input
type when constructing a request, and a model or response type when passing
SDK data between components or functions. You can also use indexed access for
a nested type, such as `Product['variants'][number]`.

The general-information API's `Region` and `City` are exported as
`GeneralRegion` and `GeneralCity`. The shorter `Region` and `City` names refer
to the shared region models. `CMSPage` is the CMS API alias; `CmsPage` is the
shared search model.

## API module types

For host props, dependency injection, or helper signatures, the module classes
are available as types: `ProductsAPI`, `CategoriesAPI`, `CartAPI`, `OrdersAPI`,
`InvoicesAPI`, `ShippingAPI`, `PaymentsAPI`, `UsersAPI`, `SearchAPI`,
`FeedbacksAPI`, `WalletAPI`, `CMSAPI`, `ImagesAPI`, `VisitsAPI`, `BookingAPI`,
`EntityRoutesAPI`, `MenuAPI`, `GeneralAPI`, `DynamicFormsAPI`, and `RegionsAPI`.

The client and lower-level helpers are available as types too: `SazitoClient`,
`HttpClient`, `TokenStorage`, `CredentialsManager`, and `MemoryStorage`.

```ts
import type { ProductsAPI } from '@sazito/client-sdk';

function loadProduct(products: ProductsAPI, slug: string) {
  return products.get(slug);
}
```
