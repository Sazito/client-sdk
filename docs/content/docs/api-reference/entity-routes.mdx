## Method

### `entityRoutes.resolve(urlPart, options?)`

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `urlPart` | `string` | Required | URL path (e.g. `/product/shoe-123`). |
| `options` | `RequestOptions` | Optional | Per-request controls. |

Returns: `SazitoResponse<EntityRouteResponse>`.

## `EntityRouteResponse` fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `entityType` | `'product' \| 'product_category' \| 'cms_page' \| 'blog_page' \| 'unknown'` | Required | Resolved entity type discriminator. |
| `entityId` | `number` | Required | Resolved entity ID. |
| `url` | `string` | Required | Resolved URL path. |
| `entity` | `Product \| ProductCategory \| CmsPage \| BlogPage` | Optional | Present when `entityType` is not `unknown`. |

## Example

```ts
const route = await client.entityRoutes.resolve('/product/running-shoe-pro');

if (route.data?.entityType === 'product') {
  console.log(route.data.entity?.name);
}
```
