## Requirements

- Node.js 18+ for server environments.
- A runtime with `fetch` support.
- A valid store domain.

## Install

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>

<Tab value="npm">

```bash
npm install @sazito/client-sdk
```

</Tab>

<Tab value="pnpm">

```bash
pnpm add @sazito/client-sdk
```

</Tab>

<Tab value="yarn">

```bash
yarn add @sazito/client-sdk
```

</Tab>

<Tab value="bun">

```bash
bun add @sazito/client-sdk
```

</Tab>

</Tabs>

## Create a client

<Tabs items={["Next.js", "Nuxt", "React", "Vue"]}>

<Tab value="Next.js">

```ts
// app/lib/sazito-client.ts
import { createSazitoClient } from '@sazito/client-sdk';

export const sazito = createSazitoClient({
  domain: process.env.NEXT_PUBLIC_SAZITO_DOMAIN!,
});
```

</Tab>

<Tab value="Nuxt">

```ts
// plugins/sazito.client.ts
import { createSazitoClient } from '@sazito/client-sdk';

export default defineNuxtPlugin(() => {
  const config = useRuntimeConfig();
  const sazito = createSazitoClient({
    domain: config.public.sazitoDomain,
  });

  return { provide: { sazito } };
});
```

</Tab>

<Tab value="React">

```ts
// src/lib/sazito.ts
import { createSazitoClient } from '@sazito/client-sdk';

export const sazito = createSazitoClient({
  domain: import.meta.env.VITE_SAZITO_DOMAIN,
});
```

</Tab>

<Tab value="Vue">

```ts
// src/lib/sazito.ts
import { createSazitoClient } from '@sazito/client-sdk';

export const sazito = createSazitoClient({
  domain: import.meta.env.VITE_SAZITO_DOMAIN,
});
```

</Tab>

</Tabs>

<Callout type="info">
  Pass domain without protocol. Example: <code>mystore.sazito.com</code>.
</Callout>

<Callout type="warning">
  Use your store subdomain on <code>sazito.com</code>. Do not pass <code>https://</code>, and do not pass root <code>sazito.com</code>.
</Callout>

## Import entity APIs directly

```ts
import { products, cart, orders } from '@sazito/client-sdk';

const productsApi = products({ domain: 'mystore.sazito.com' });
const cartApi = cart({ domain: 'mystore.sazito.com' });
const ordersApi = orders({ domain: 'mystore.sazito.com' });
```

Each alias maps to the same module surface available on
<code>createSazitoClient(...)</code>:
<code>products</code>, <code>categories</code>, <code>cart</code>,
<code>orders</code>, <code>invoices</code>, <code>shipping</code>,
<code>payments</code>, <code>users</code>, <code>search</code>,
<code>feedbacks</code>, <code>wallet</code>, <code>cms</code>,
<code>images</code>, <code>visits</code>, <code>booking</code>,
<code>entityRoutes</code>, <code>menu</code>, and <code>general</code>.
