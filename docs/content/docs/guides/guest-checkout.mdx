## Recommended (orchestrated) flow

Use `client.checkout.initialize(...)` as the default integration path.
It runs the MVP sales flow automatically and returns the next payment action.

```ts
const checkoutRes = await client.checkout.initialize(
  {
    variantId: 12345,
    count: 2,
    shippingAddress: {
      firstName: 'John',
      lastName: 'Doe',
      mobilePhone: '09123456789',
      regionId: 1,
      cityId: 10,
      address: 'No. 10, Example St',
      postalCode: '1234567890',
    },
  },
  {
    onSuccess: ({ order }) => {
      console.log('Checkout completed:', order.orderNumber);
    },
  }
);

if (checkoutRes.error) {
  throw new Error(`${checkoutRes.error.details?.step}: ${checkoutRes.error.message}`);
}

const action = checkoutRes.data?.paymentAction;

if (action?.action === 'UPLOAD') {
  await client.checkout.processPaymentStep({
    imageUrl: 'https://cdn.example.com/payment-proof.jpg',
    code: '123456',
  });
}
```

## Manual modules flow (advanced fallback)

If you need full step-by-step control, use module APIs directly:
`cart`, `invoices`, `shipping`, and `payments`.

## Operational notes

- `checkout.initialize` automatically handles cart creation, invoice sync, and default payment method selection.
- When `paymentAction.action === 'showOrder'`, checkout is completed and `onSuccess` receives final order data.
- `checkout.processPaymentStep` and `checkout.pollPaymentUntilSettled` handle step-based or pending gateways.
